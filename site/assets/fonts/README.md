# Chapter typeface

`../chapter-wenkai.woff2` is a web-only glyph subset of LXGW WenKai Regular from [the upstream project](https://github.com/lxgw/LxgwWenKai/tree/50f4b182415a8c33d9a456df220b66a284e2509b), revision `50f4b182415a8c33d9a456df220b66a284e2509b`. The original file is `fonts/TTF/LXGWWenKai-Regular.ttf`.

It contains digits and the seven chapter names used on this site. Generated with fontTools `pyftsubset --flavor=woff2`. No glyph outlines were changed. The upstream OFL license and its additional web-subsetting permission are preserved in `OFL-WenKai.txt`.
